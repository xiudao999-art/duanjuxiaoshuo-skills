# Narrative lens library

Choose one primary lens per story window. A lens selects and orders evidence; it does not authorize invented plot facts. Record a separate `storyType` from the six-category production taxonomy in `whole-series-planning.md`; category describes what story is promised, while lens describes how it is told.

| Lens ID | Selection rule | Required beat path |
| --- | --- | --- |
| `linear_escalation` | One conflict grows through a coherent episode span | abnormality → cause → escalation → reversal → payoff |
| `result_first` | A later visible result has a strong unanswered cause | result → rewind → desire → wrong choice → escalation → result explained |
| `mystery_reveal` | One answerable mystery has distributed clues | mystery → suspects → clues → false explanation → decisive proof → truth |
| `causal_domino` | One choice produces a chain of consequences | choice → small cost → second-order cost → loss of control → irreversible result |
| `countdown_rescue` | A deadline, chase, escape, or rescue controls the story | danger → time limit → obstruction → near failure → decisive act → consequence |
| `parallel_contrast` | Two characters face comparable pressure differently | shared problem → A choice → B choice → intercut consequences → convergence |
| `character_growth` | One character changes through consequential choices | wound or need → goal → failure → cost → turning choice → changed identity |
| `hidden_identity` | Suspicion and evidence lead to an identity reveal | presented identity → contradiction → test → near exposure → public reveal |
| `romance_progression` | Relationship actions change trust or commitment | attraction → obstacle → misunderstanding → proof of care → sacrifice or choice |
| `alliance_betrayal` | Loyalty changes alter the balance of power | trust → anomaly → betrayal → isolation → new alliance → counterattack |
| `villain_downfall` | Wrongdoing creates the evidence of defeat | power display → wrongdoing → victim plan → evidence → public reversal → cost |
| `action_escalation` | Fights share one objective and rising opposition | threat → objective → first clash → stronger obstacle → tactical reversal → result |
| `status_reversal` | Humiliation is answered by evidence, ability, or identity | humiliation → restraint → opponent escalation → proof → public reversal |
| `family_redemption` | Family harm changes through truth and action | wound → misunderstanding → truth → protective choice → repair or separation |
| `motif_clue` | One object, line, document, or mark links distant events | appearance → transfer → anomaly → rediscovery → meaning revealed |
| `dialogue_showdown` | Verbatim confrontation changes a relationship or decision | stakes → claim → denial → evidence response → irreversible declaration |

## Recommended category mapping

| storyType | Preferred lenses |
| --- | --- |
| `continuous_plot` | `linear_escalation`, `result_first`, `causal_domino`, `countdown_rescue` |
| `character_arc` | `character_growth`, `villain_downfall`, `result_first` |
| `relationship_arc` | `romance_progression`, `alliance_betrayal`, `family_redemption`, `parallel_contrast` |
| `action_payoff` | `action_escalation`, `status_reversal`, `countdown_rescue` |
| `mystery_reveal` | `mystery_reveal`, `hidden_identity`, `motif_clue`, `villain_downfall` |
| `special_theme` | `parallel_contrast`, `motif_clue`, `dialogue_showdown`, `causal_domino` |

The mapping is guidance, not a hard pairing. Require the category qualification even when using a less common lens.

## Lens rules

- Do not make `action_escalation` a random fight montage; preserve objective, opposition, tactic, and consequence.
- Do not make `romance_progression` a collection of affectionate shots; include a relationship-changing choice.
- Do not make `dialogue_showdown` a quote compilation; retain enough context for each line's force and preserve complete utterances.
- Use `result_first` only when the borrowed result is paid back in the same video.
- Use `parallel_contrast` only when the compared events share a meaningful question.
- Use a secondary lens only as a tag. The primary lens controls event order and scoring.
