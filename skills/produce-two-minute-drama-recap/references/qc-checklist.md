# QC checklist

## Story

- [ ] The episode window contains 4–8 consecutive episodes.
- [ ] One central question controls the whole recap.
- [ ] The hook creates a visible abnormality and is paid back.
- [ ] The story contains 6–8 causal units and at least 3 real turns.
- [ ] No 20-second span is informationally flat.
- [ ] Conflict cost escalates instead of repeating.
- [ ] The ending completes a visible choice before opening a consequence.

## Script and dialogue

- [ ] Approved narration facts are supported by episode evidence.
- [ ] Stable character labels prevent pronoun ambiguity.
- [ ] Every turn word introduces new information.
- [ ] Dialogue is verbatim, complete, and stronger than paraphrase.
- [ ] Dialogue boundaries include safe pre-roll and 0.30–0.50 seconds post-roll where available.
- [ ] Narration never overlaps source speech.

## Picture

- [ ] Narration shots match character, action, location, and state.
- [ ] B-roll is normally 2–4 seconds; longer reaction shots are justified.
- [ ] No source shot or overlapping source range is repeated unless an intentional callback is documented.
- [ ] No wrong-character substitution occurs.
- [ ] No lower-frame shadow mask obscures footage.
- [ ] The source notice stays visible in the upper-right safe area.

## Captions and effects

- [ ] Caption text comes from the approved script; ASR supplies timing only.
- [ ] Display captions follow the requested punctuation policy.
- [ ] Every cue boundary falls between Chinese words; no name, title, relationship label, or protected compound is split.
- [ ] Concatenated caption cues reproduce the approved script exactly.
- [ ] Two-line baseline spacing is at least `1.65 × font size`; heavy outlined text normally uses `1.75–1.85 ×`.
- [ ] Encoded frames containing ordinary and CK two-line captions show visible air between glyphs, outlines, and shadows.
- [ ] Ordinary caption entry animation remains readable.
- [ ] CK events replace ordinary cues and use meaningful templates.
- [ ] Every CK phrase has an exact or high-confidence audited match.
- [ ] SFX starts with the visual event and stays below dialogue.

## Technical

- [ ] Output matches requested canvas and frame rate.
- [ ] Narration is retimed to the declared narration speed; source drama picture, hook audio, and dialogue remain at 1.0×.
- [ ] Caption and CK clocks follow the mixed output timeline rather than a global speed divisor.
- [ ] Narration-block and dialogue-block speech loudness medians are closely matched before final mastering.
- [ ] Every edit boundary has click prevention.
- [ ] No black or frozen frames appear unexpectedly.
- [ ] Integrated loudness is approximately -15 to -13 LUFS.
- [ ] True peak is at or below -1 dBTP.
- [ ] The final file opens, seeks, and reports the expected duration.
- [ ] The final narration block includes at least 0.45 seconds planned tail and at least 0.35 seconds measured trailing silence.
