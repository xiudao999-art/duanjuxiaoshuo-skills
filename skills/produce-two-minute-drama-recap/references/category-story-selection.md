# Category-specific story selection

Read this reference before expanding a candidate into narration. It defines
which source events belong in each `F01`–`F10` family. The rules were validated
against one 20-minute source sequence and four different compressed recaps of
the same plot.

Category controls event selection and order. It must not leak analytical terms
such as “power structure,” “closed-loop verification,” or “identity
sovereignty” into the spoken narration.

## Evidence priority inside a candidate

Classify each proposed event before selection:

- `A causal spine`: removing it makes the next core action unexplained;
- `B motive evidence`: action remains possible without it, but the character's
  choice becomes abrupt;
- `C category evidence`: useful only for the assigned F family;
- `D decoration_or_repeat`: repeated reaction, equivalent abuse, unrelated
  mystery, biography, or spectacle that changes nothing.

Every accepted window keeps all required A events, enough B events to make
choices credible, and only the C evidence required by its family. Reject D by
default.

## F01 Causal plot window

Required event slots:

```text
abnormal result or current objective
→ direct cause
→ at least two distinct obstacles
→ evidence or information reversal
→ visible action result
```

Selection rules:

- Use the removal test: if deleting an event does not affect the next core
  action, it is not part of the causal spine.
- Keep a departure, call, document, trace, or pursuit action for every major
  time or location jump.
- A flashback remains only when it explains the present relationship, present
  risk, or a payoff ability.

Reject:

- events joined only by topic;
- biography that does not alter a later choice;
- a time jump with no causal bridge.

## F02 Character strategy or transformation

Required event slots:

```text
old goal or habitual tactic
→ old tactic fails
→ concrete cost
→ evidence changes the character's judgment
→ visibly different choice
```

Selection rules:

- Select contrasting behavior by the same person before and after the turn.
- Preserve one old-goal scene even when it looks less dramatic than the later
  payoff; without it there is no observable change.
- Use care, investigation, sacrifice, refusal, or protection as proof of the
  new strategy.

Reject:

- a highlight reel containing only the transformed state;
- antagonist biography unrelated to the choice;
- narration-only claims of growth.

## F03 Relationship state transition

Required event slots:

```text
initial relationship state
→ boundary event
→ receiving reaction
→ visible trust or hostility change
→ test of the new state
→ choice or action confirms it
```

Selection rules:

- Keep scenes where a promise, refusal, defense, sacrifice, or accepted address
  changes what the two characters may do next.
- A child or intermediary may recur only when each appearance performs a new
  relationship function.
- Preserve complete question-answer-reaction dialogue at the actual state
  transition.

Reject:

- affectionate-shot montages with no relationship choice;
- repeated cute reactions that do not alter the bond;
- promises with no later test or fulfillment; mark them `conditional` instead.

## F04 Antagonist mechanism

Required event slots:

```text
antagonist objective
→ control lever
→ person or rule enforcing it
→ victim loses an option
→ concrete beneficiary and gain
→ first mechanism failure
```

Selection rules:

- Select one strongest event per control level: deception, access restriction,
  bodily control, dependent-person threat, resource seizure, final perpetrator.
- Keep the exact asset or privilege being transferred.
- Keep the failure point that shows how the mechanism can be broken.

Reject:

- synonymous insults;
- repeated pulling or crying at the same threat level;
- hero identity lore that does not expose or break the mechanism.

## F05 Ability or credibility proof

Required event slots:

```text
ability disputed
→ first visible test
→ harder test or command
→ result delivered
→ another person's behavior changes
```

Selection rules:

- Prefer a task with observable input and result.
- A title, kneeling subordinate, or luxury vehicle is supporting evidence only.
- Keep the command and its later fulfillment as a pair.

Reject:

- title-only proof;
- repeated easy wins with no difficulty escalation;
- romance or lineage facts unrelated to the tested ability.

## F06 Rule, resource, or economic game

Required event slots:

```text
resource named
→ starting controller
→ allocation rule
→ attempted rule change
→ actual transfer or refusal
→ concrete consequence
```

Selection rules:

- Map who gives what to whom, under which condition.
- Prefer a resource with dual value: money or status to one side, survival,
  relationship, or moral value to the other.
- Keep emotional scenes only when they change resource control.

Reject:

- money amounts with no ownership change;
- “for the family's benefit” without a beneficiary and asset;
- a kiss, promise, or insult treated as economics only through narration.

## F07 Action, crisis, rescue, or public counterattack

Required event slots:

```text
named victim and danger
→ first option removed
→ stronger danger
→ distress or location signal
→ rescuer crosses an obstacle
→ arrival, rescue, or visible counterattack
```

Selection rules:

- In the victim line, select one event per reduction in escape options.
- In the rescuer line, select only evidence, location, mobilization, and
  distance-changing action.
- Keep a complete distress line when it transmits irreplaceable information.
- Use a two-line edit only when the lines visibly converge.

Reject:

- hero biography unrelated to the current rescue;
- same-level fight montage;
- two intercut lines that never meet in available footage.

## F08 Identity, mystery, clue, or reveal

Required event slots:

```text
one explicit identity question
→ two to four increasingly specific clues
→ old explanation or misdirection
→ decisive proof
→ confirmation changes the next action
```

Selection rules:

- One two-minute window has one primary mystery.
- Other identity facts remain only when they directly change the main answer
  or payoff action.
- End with confirmation or irreversible new evidence.

Reject:

- lost heir, secret leader, parentage, and hidden enemy as four equal questions;
- clues with no visible or spoken evidence;
- a promised reveal beyond the available source. Mark it `conditional`.

## F09 Motif, prop, phrase, or behavior recurrence

Required event slots:

```text
first occurrence establishes meaning
→ second occurrence creates anomaly
→ third occurrence changes relationship or evidence meaning
→ final occurrence triggers action or reveal
```

Selection rules:

- Permit distant episodes when the same verified object, phrase, address, or
  behavior changes function.
- Record the different function at every occurrence.
- Prefer transfer, use, damage, rediscovery, or changed addressee over repeated
  close-ups.

Reject:

- recurrence with unchanged meaning;
- visually similar objects with no verified identity link;
- props nobody uses and that cause no decision.

## F10 Alternate perspective, contrast, irony, or comedy

Required event slots:

```text
same question or pressure
→ A response or presented identity
→ B's opposing response or real identity
→ contrast becomes visible to a third party or creates consequence
```

Selection rules:

- Pair scenes by the same governing question, not by mood.
- For ordinary-cover versus real-power contrast, first stabilize the ordinary
  behavior, then show operational power.
- For romantic-threat comedy, resolve the expectation gap within 3–8 seconds.

Reject:

- random joke compilations;
- before/after scenes that answer different questions;
- comedy inserted after serious illness, coercion, or child danger activates.

## Category-specific dialogue selection

- `F01`: retain dialogue only when it creates the next causal action.
- `F02`: retain the old rule or the turning-choice declaration.
- `F03`: retain promise, refusal, allegiance, breakup, or relationship address.
- `F04`: retain the controlling condition, threat, or explicit beneficiary.
- `F05`: retain the challenge, command, test result, or public acceptance.
- `F06`: retain the offer, price, allocation condition, or transfer refusal.
- `F07`: retain distress information, mobilization command, or counterattack line.
- `F08`: retain clue denial, identity claim, or decisive reveal.
- `F09`: retain the repeated phrase only when its addressee or meaning changes.
- `F10`: retain the expectation-setting line and its punchline or contradiction.

Dialogue from another family does not enter merely because it is memorable.

## Pre-narration selection record

Before writing 500–650 characters, record:

1. family ID and one category-specific selection pattern;
2. required slot → event ID mapping;
3. A/B/C/D grade for every proposed event;
4. the event removed by the last deduplication pass;
5. hook promise and available payoff evidence;
6. why every episode or time jump is necessary.

Reject the candidate when any required slot has no supported event. Do not fill
the missing slot with analytical narration.
